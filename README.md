# Sistema de Gestão de Leitura - Painel Avançado v3.5

Este projeto é uma ferramenta avançada de gerenciamento e acompanhamento de leitura, focada em rankings, gestão de atrasos e controle de pendências.

## 🚀 Funcionalidades

- **Dashboard Geral:** Visão consolidada de todos os indicadores.
- **Gestão de Lojas e PDVs:** Controle detalhado por unidade.
- **Rankings (Boas + Perfeitas):** Sistema de pontuação e troféus.
- **Gestão de Atrasos:** Alertas visuais para itens fora do prazo.
- **Controle de Pendências:** Listagem e acompanhamento de tarefas.
- **Time de Campo:** Gestão da equipe operacional.
- **Backup e Restauração:** Segurança dos dados via arquivos JSON.
- **Exportação para Excel:** Relatórios prontos para análise externa.

## 🛠️ Tecnologias Utilizadas

- **HTML5 / CSS3** (com Tailwind CSS para estilização)
- **JavaScript (Vanilla)**
- **Chart.js** (para visualização de dados)
- **SweetAlert2** (para notificações interativas)
- **SheetJS (XLSX)** (para exportação de dados)
- **Font Awesome** (para ícones)

## 📦 Como usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/gerenciamento-leitura.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno.
